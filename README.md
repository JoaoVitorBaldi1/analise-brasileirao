#  Análise do Brasileirão com Python e Pandas

Um projeto desenvolvido para praticar análise de dados utilizando **Python** e **Pandas**, explorando estatísticas do Campeonato Brasileiro.

##  Objetivo

O objetivo deste projeto é aplicar conceitos fundamentais de Ciência de Dados e programação em Python por meio da análise de um conjunto de dados contendo partidas do Campeonato Brasileiro.

O programa permite consultar estatísticas de um time específico e gerar rankings gerais do campeonato.

---

##  Tecnologias utilizadas

* Python 3
* Pandas
* Git
* GitHub

---

##  Funcionalidades

### Estatísticas por time

O usuário pode consultar:

* Total de jogos
* Número de vitórias
* Número de empates
* Número de derrotas
* Aproveitamento (%)
* Gols marcados
* Gols sofridos
* Saldo de gols

---

### Estatísticas do campeonato

O programa também permite visualizar:

*  Melhor ataque
*  Melhor defesa
*  Ranking dos melhores ataques
*  Ranking das melhores defesas
*  Ranking de vitórias

---

## ▶ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/JoaoVitorBaldi1/analise-brasileirao.git
```

2. Entre na pasta do projeto:

```bash
cd analise-brasileirao
```

3. Instale as dependências:

```bash
pip install pandas
```

4. Execute o programa:

```bash
python analise.py
```
